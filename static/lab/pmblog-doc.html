安装配置

  1. 打开config.php，修改相应常量。其中BLOGURL为你的网站网址，TEMPLATE为你的主题文件夹，请保证填写的主题文件夹存在。MD和HTML都对应文件夹路径，填写为相对路径即可。
  2. 打开浏览器访问index.php

常见问题

1. 一定要本地PHP环境么？

一般来说你有两种搭配模式可以选择：

  • 本地+Github/Gitcafe/SAE：在本地搭建好程序，生成好网站后将所有静态页面上传到Github Page/Gitcafe Page/SAE中
  • 虚拟主机/VPS：将程序上传到主机中，每次写好的文章上传到相应目录后运行程序生成网站

所以本地PHP环境不是必须，你也可以选择支持PHP的虚拟主机/VPS。

2. 更新文章刷新没有反应？

多刷新几次或清空缓存试试。

3. 如何更新文章？文章支持什么格式？

在config.php中定义了你的文章需要上传的文件夹，默认是md文件夹。将写好的文章上传到md文件夹，然后访问index.php即可更新网站。

目前程序支持解析.md, .txt, .html, .htm等文本类型格式文件（即用记事本能打开的类型）。

4. 如何增加评论功能？

在config.php中定义了一个$comment变量，将社会化评论代码添加到其中即可。例如：

//社会化评论代码{请放在两个EOD之间}
$comment = <<<EOD
<!-- Duoshuo Comment BEGIN -->
    <div class="ds-thread"></div>
    <script type="text/javascript">
    var duoshuoQuery = {short_name:"abc"};
    (function() {
        var ds = document.createElement('script');
        ds.type = 'text/javascript';ds.async = true;
        ds.src = 'http://static.duoshuo.com/embed.js';
        ds.charset = 'UTF-8';
        (document.getElementsByTagName('head')[0] 
        || document.getElementsByTagName('body')[0]).appendChild(ds);
    })();
    </script>
<!-- Duoshuo Comment END -->
EOD;

5. 如何增加搜索功能？

为网站添加搜索功能

6. 如何更换主题？

config.php文件中定义了你当前主题的文件夹，默认是default。将你下载好的主题放置到tmp文件夹下，修改config.php中的主题文件夹定义代码后既可实现更换主题。

//博客模板
define('TEMPLATE', 'twentytwelve');

注： PMBlog主题大全

7. 首页支持自定义输出么？

程序支持非全文输出，即部分输出。在撰写文章时，在想要输出的文字后面添加<!--more-->程序将在首页不输出其之后的文字，并添加一个全文链接。

8. 为什么生成的页面乱码？

这种情况有两种原因：

  • 你的主题没有定义页面代码，在header.html的<head>和</head>添加<meta charset="utf-8" />即可解决
  • 你的文章文件的编码类型非utf-8（使用Windows自带的记事本撰写文章会碰到这种情况）

9. 如何自定义导航？

需要在主题中手动添加导航链接然后重新生成网站。

写作规则

基本规则

  • 文件名即文章的URL名，也是文章的ID
  • 文件创建时间为文章标题
  • 文件内容，即文章正文

进阶规则

在文章的第一行开始，可以进行标注（标注非必要，按需即可）

title: 这里写你的文章标题

date: 这里写文章的发表时间，默认为文本文件的创建时间

type: page (可选page/post两个参数，默认为post)

status: draft (draft的文章不会被别人看到)

tags: Tag1， Tag2

template: guestbook （自定义页面模板）

  1. 如果没有标注Title, 文件的创建时间即是文章的标题。
  2. Date标注最好不要夹带中文，容易造成BUG。推荐写成1949-10-01 10:00:00或者1949/10/01 10:00:00这种形式
  3. Type标注只支持page/post两个参数，如果为page将指定此文章作为页面形式发表。
  4. Template定义的模板必须存在，如果不标注此参数，则默认文章模板为blog.html, 默认页面模板为page.html

补充说明

  1. 为了让URL地址看起来更友好，建议不要使用汉字作为文件名，尽量使用英文（拼音也挺好的）并使用非空格字符（例如-）连接单词
  2. 最终生成的URL地址文章地址会加上/post/前缀，页面地址会加上/page/前缀

各页面的变量

页面名变量
全局变量{BLOGURL} {BLOGTITLE} {RECENTPOST} {comment}
首页 index.html{title} {url} {filename} {date} {content} {tags}
文章详细页 post.html{title} {url} {filename} {content} {tags} {PREVPOST} {NEXTPOST}
页面详细页 page.html{title} {url} {filename} {content} {tags}{archive}

页面变量详细说明

  1. 首页模板变量中{title} {url} {filename} {date} {content} {tags}这几个变量必须在{each:start} {each:end}之间使用方有效，否则会报错。
  2. 首页模板变量{content}支持自定义字段，例如{content:阅读更多}会在文章非全文输出的时候再文末加上文章链接代码，默认字段为阅读全文。注：此自定义字段只在首页模板中有效。
  3. {date}变量支持自定义字段，例如{date:Y-m-d}将生成形如1949-10-01这种类型的时间格式。自定义字段的格式代码可以参考：date, 默认格式为config.php中定义的DATEFORMAT
  4. {PREVPOST}和{NEXTPOST}支持自定义字段来自定义输出格式。例如{PREVPOST:%s →}输出形如Hello World!→格式的内容，其中%s表示需要被程序替换的字段。{NEXTPOST}的自定义形式和效果和{PREVPOST}一样。
  5. {tags}变量支持自定义字段，例如{tags:',','true','No Tags'}中第一个参数,定义了标签的连接符，第二个参数true定义输出带连接的标签，反之则为false，第三个参数定义了当未定义标签时默认显示的文字。其中需要注意的是第二个参数一定要加上引号，每个参数之间用,严格分开，不允许有多余的空格出现，否则会报错。定义参数的时候要么都不定义，一定义则全部需要定义。按照顺序（例如只定义第一个参数或者定义第一个第二个参数）定义的话可以省略后面不需要定义的参数，例如{tags:','}和{tags:',','false'}都是被程序认可的。

页面函数

页面名页面函数
全局变量{link:}
首页 index.html{each:start} {each:end}

页面函数详细说明

  1. {link:*}函数中将*替换成除后缀的文件名，即可将对应页面添加进其中。例如{link:header}即是在当前页面中包含了header.html。
  2. {each:}函数需要{each:start}和{each:end}搭配使用方才有效，并只在首页中才有效。
