# Firekylin Example

This directory is a brief example of a [Firekylin](https://github.com/firekylin/firekylin) app that can be deployed with Vercel and zero configuration.

## Deploy Your Own

Deploy your own firekylin project with Vercel.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/import/project?template=https://github.com/firekylin/vercel-starter)

### How We Created This Example

```js
npx firekylin new blog
```
